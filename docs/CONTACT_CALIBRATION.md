## 实际实现与单位

1. 几何、质量、惯性、经验水动力/阻力/力矩系数不变。原耦合中点改为经典四阶段RK4：`y1=y0+h*(k1+2k2+2k3+k4)/6`，状态为p(m)、v(m/s)、L(kg·m²/s)、q（无量纲）；`q'=0.5*(omega,0)*q`。各阶段重新计算水动力和角速度，RK中间q保持原始线性状态，几何/惯性使用其单位化副本，接受步最终q归一化。
2. 近水处4个基础子步，不是提高全局子步数：DT/4=62.5µs，半步31.25µs。远场干燥间距超过`2*(|v|+.04m*|omega|+9.81m/s²*dt)*dt`时只做1步；.04m取盘面最大半径，系数2为远场切换安全余量，不影响接触/计分定义。几何旋转包络、飞行速度用于远场开关，未做完整碰撞区间证明。
3. 四个阶段/候选终点湿干或全浸没状态不同，以及阶段迎流压力分支变化时，局部二分并重新积分，最多11层；拒绝候选不修改物理/事件状态。近水边界分辨率为DT/4/2048=30.5176ns，半步15.2588ns；这是局部时间区间上界，不等于全程轨迹误差保证，也不是固定共享内部网格。默认接受步数27251/53284，最小dt确实减半。
4. Contact时间和end取接受湿/干步的起点；所有阶段全干才关闭。仍仅在干燥关闭且v.y>0、未全浸没时计一次跳。没有最小跳高、出水速度或大间隙合并，没有硬钉跳数、强制出水。几何接触保持原定义，因此不存在“被阈值去掉的小跳数”。新增浅掠测试在1e-7m初始浸入深度、0.02m/s上升速度下，持续小于31.25µs的弱真实接触仍被记录并计分，冲量为正，DT与半步时序一致。
5. impulse改为与受力积分相同的四阶段`∫|Fwater|dt`（N·s），netImpulse为`∫Fwater dt`；都不包括重力及空气阻力。新增可选centroid(m)、normal(单位盘法线)、netImpulse(N·s)、exitVelocity(m/s)，不要求旧Contact快照提供。centroid/normal为最新接受湿步第二个RK中点，point/velocity仍固定入水值。干燥切点起始无面积时，以切点内1pm的几何极限求point偏移，只影响定位，不参与力/事件/计分。终止沉水的Contact可无exitVelocity。后续效果可消费这些字段，本轮未修改效果或UI。

## 难例与不能声称的结论

- 唯一跳数残余：14m/s、10°，before15/10，after14/20。虽然分歧病例减少，**该单例跳数绝对差5→6有所退化**，不宣称计数全面收敛。最终径向差仅0.000239103m并不能代表事件一致。
- 该例首次接触时刻两精度相差约1.5e-14s；第三次约30.5ns，第四次0.168µs，第六次8.48µs，第七次61.1µs，第十次0.442ms。前段并无单步干湿抖动，误差逐次放大；到1.14079s fine多出持续0.838ms、冲量1.14357e-7N·s且未计分的弱接触，其后两条轨迹出现10至50ms、有显著冲量的不同接触序列。不能把这些全部合并成同一次真跳。日志更支持姿态/湿面积/力矩反馈在临界末段的敏感性，而不是只靠更准确入水时间就能解决。
- 最大最终径向误差来自14m/s、20°：0.001156695m，匹配事件时差0.293488ms；14m/s、14°径向误差0.000078909m、时差22.705µs。原四组跳数分歧已消失，但不表示任意参数都收敛。
- 独立`npm run sweep`仍有最大共同10ms时刻三维轨迹差0.055208041m（上一轮基线0.145347881m，改善62.0%），最终X差max0.001151255m。不同结束时间不拿“停住后的石子”做轨迹比较。轨迹差主要来自剩余难例，不能用很小的最终距离误差掩盖中途路径误差。
- 下一轮应针对剩余难例分段记录角动量/盘法向/湿面积与压力中心轨迹，尝试有实际局部误差估计的高阶自适应/边界连续延拓，并研究分布局部速度压力。不能仅凭当前工程结果声称经过实物科学标定；本轮不改变现有流体近似。
