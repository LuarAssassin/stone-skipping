# 掠水 · 第二批世界地标 3D 场景资产 Blender 制作规范（Wave 2 Scene Packs）

本规范用于离线生成 **5 套极具国家与地域辨识度的世界地标水景资产包**（共 32 件 `.glb`），完全沿用第一批 `tools/blender/scene_pack_factory.py` 与 `tools/blender/validate_scene_pack.mjs` 的高质量管线：
- **1 Blender unit = 1 meter**，glTF 2.0 `Y-up`（`export_yup=True`），应用全部变换。
- **原点规则**：水上漂浮物与涉水建筑原点严格在 **静水面 `y = 0`**（船底/竹筏下探 `-0.25 ~ -0.45 m`，水桩/石墩/石柱下探 `-1.20 m`）；岸上树木、远景地标山峰原点在 **接地面 `y = 0`**（底部微下探 `-0.20 ~ -0.60 m` 防悬空）。
- **宽幅远景朝向约定**：所有远景山体/群峰/岛屿（`X` 轴为横向宽面，`Z` 轴为前后纵深），Three.js 侧会统一绕 Y 轴旋转 `±π/2` 面向玩家。
- **材质与贴图**：全量展开 UV 并烘焙内嵌 WEBP PBR 贴图（`BaseColor + Roughness + Normal`，大件 `1024×1024`，小件 `512×512`）；树叶/樱花/竹叶/纸莎草/落瓣用 `alphaMode='MASK'`；灯笼、窗光、火盆用独立暖色 `Emissive` 材质。
- **每套交付**：
  - `public/assets/scenes/<packId>/*.glb` + `manifest.json`（与第一批同结构）
  - `tools/blender/generate_<packId>_scene.py`（固定 seed，跨次复跑逐字节一致）
  - `tools/blender/preview_<packId>_assets.png`（Cycles 散光网格验收图）
