# 岸后全景与多镜头回放

## 使用

默认从出手点后方抬高、朝湖面观察整段弹跳，机位不随石子移动。右侧（手机下方）常驻「观察视角」「播放速度」；全景构图参数与开发参数分别折叠，不必打开开发详情才能换镜头。

- **岸后全景 · 固定**：默认高度9m、岸后距离9m、方位18°、注视湖面前方6m、垂直FOV48°。
- **近景跟随**：保留局部跟随观察，机位和目标随石子平移。
- **正常1×**、**普通慢放0.25×**：只改变物理/效果时钟速度，不自动换掉用户视角。
- **子弹时间0.05×**：临时覆盖用户镜头，绕石子旋转并缓慢变距、起伏。水平半径0.75–1.05m、角速度0.65rad/s；目标在石子附近，不是把原跟随减速。机位最低0.16m，平滑过渡后仍有0.12m安全下限，不进入水下。
- **暂停**：冻结模拟、效果、presentationTime及子弹轨道。继续从同一相位运行；退出子弹时仍可平滑回到用户选择的固定/跟随视角。
- **全景构图参数**：高度2–20m、后退2–25m、方位±65°、注视距离3–30m、FOV30–75°。重置仅还原全景参数，不重投、不抽seed、不改视角选择。

相机使用指数平滑（约0.2s时间常数）过渡位置、注视点和FOV；不会瞬间切到另一个位置。岸沿只是给出手点后方提供空间参照的平面，不参与碰撞、水体或物理。湖面仍是原来有限平面；不是景观系统。

## 回放契约

Session拥有sim、ContactEffects、快照、暂停和两个时钟。presentationTime随真实播放时间推进，不乘0.25或0.05；因此慢动作时环绕仍可读，而不是几乎静止的跟拍。visualTime与物理固定步同步，沉水后只继续已有水花寿命。RAF分组不会改变物理步长。

新投掷（按钮、R、手势）抽一个新seed，清空轨迹/效果与时钟，恢复正常1x；初始温度仍为T1，开发者显式更改温度后按其选择投掷。保留用户视角与全景构图参数。重放使用同一version/seed/temperature/target/sampled快照，不再次抽seed；后改滑块或手势预览不能影响快照。JSON载入仍先经原校验器验证。重放保留当前播放模式，便于连续观看同一投掷的慢放或环绕；可随时选回1x。

物理积分、随机数/抽样算法、水面shader、薄片/细滴算法和基准JSON均未修改。新功能只增加相机、会话与界面编排，不改变真实米制石子大小、质量或动力学。
