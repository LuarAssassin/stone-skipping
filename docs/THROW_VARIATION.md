# 投掷扰动温度 · v1

## 范围与语义

温度是无量纲随机强度，不是摄氏度：0无扰动实验，1默认自然微扰，最大2。仅在新投掷按钮或R抽样一次实际出手，之后不再抽样。没有风、水环境随机，没有隐藏弹跳、随机跳数、积分常数变化；原物理解析接触、角动量、GPU波纹细滴均保留。技巧决定目标输入与成功范围，不保证某个跳数。

`src/launch-randomness.ts` 是无浏览器依赖的纯模块。原Launch、DEFAULT、Simulation和效果算法未改；直接使用Simulation仍是确定的实验基线。新seed只在页面新投掷时通过crypto.getRandomValues获取uint32。重放没有crypto调用；暂停前未投掷的重放不启动模拟。

## 分布与公式

显式uint32 Mulberry32 PRNG：状态每次加0x6d2b79f5，异或移位和Math.imul混合，最后uint32 / 2^32。算法代码与version=1快照一起版本化。

按速度、方向、仰角、石面倾角、自旋顺序，每项独立取3个U∈[0,1)，定义 Z=2(U1+U2+U3)/3−1。Z关于0对称，有界[-1,1)，为三均匀卷积的分段二次平滑密度；理论均值0，方差1/9，非高斯且无长尾。温度线性乘Z：

| 参数 | 实际值（安全裁剪前） | T1最大幅度 | T1理论标准差 |
| --- | --- | --- | --- |
| 速度 | target × (1+0.035TZ) | ±3.5% | 1.167% |
| 方向 | target + 1.5TZ | ±1.5° | 0.5° |
| 仰角 | target + 1.5TZ | ±1.5° | 0.5° |
| 石面倾角 | target + 1.5TZ | ±1.5° | 0.5° |
| 自旋 | target × (1+0.04TZ) | ±4% | 1.333% |

T=0直接复制，不经过乘法/裁剪，严格恒等。target必须有限，speed>0、spin≥0、tilt∈[0,85]、仰角∈[-80,80]；实际仰角裁剪[-80,80]、倾角[0,85]。T≤2时速度最少为target的93%、自旋最少92%，不因扰动倒飞/负速/翻盘。零自旋保持零。边界裁剪会有偏置，不能把边界样本宣称为零均值；UI范围远离仰角上限，但零倾角仍受裁剪。没有引入相关握持误差。

## 快照与重放

快照包含version、seed、temperature、target、sampled。target复制隔离滑块对象；每次Simulation使用sampled的新副本。重放不从当前滑块重新抽样，所以之后改目标或温度也不影响旧快照。页面显示“目标 → 实际出手”和本次seed/T；JSON文本框可全选复制、点击复制或粘贴载入并重放。载入校验版本、合法参数并用种子重算逐字段核对sampled，拒绝不匹配快照（允许JSON字段重排）。不是防篡改签名，也不保证跨未来物理版本位级重现。

水花仍由同一固定物理步的接触记录派生，水滴出生随机基于接触id，不在RAF或物理step中使用Math.random。同一快照、同一运行版本和步长可复现物理及水花。

## 固定集合批测

环境：本机Linux，Node 24，原DT=1/4000秒且每外步8子步。先连续seed 0..15定位（T1跳数4:1、5:5、6:1、7:5、8:4；距离标准差0.419029m），无需加大幅度。然后不筛选地运行连续uint32 seed **0..63（含端点）**，每温度64次完整物理，共128次，均用原默认目标：11m/s、方向0°、仰角2°、倾角6°、18转/s。统计距离是最终水平径向距离hypot(x,z)，不是仅x（原回归的x为8.8451179005m，非同一指标）。

| 温度 | 跳数直方图（跳数:次数） | 距离min / mean / max (m) | 总体标准差 (m) |
| --- | --- | --- | --- |
| 0 | 4:64 | 8.846545387 / 8.846545387 / 8.846545387 | 0 |
| 1 | 4:7, 5:12, 6:12, 7:17, 8:15, 9:1 | 7.501847795 / 8.719769478 / 9.595809103 | 0.488873750 |

总体标准差=sqrt(Σ(x−mean)²/N)，非样本N−1估计；均值以首值为偏移求和，避免相同T0数值累加产生伪离散。

实际初值偏差（sampled−target），以下为完整64组T1，不是理论边界：

T0五项偏差全部严格0。完整逐seed初值/跳数/距离保存在[throw-variation-64.json](throw-variation-64.json)。复跑：`npx tsx src/variation-sweep.ts 16`或`npx tsx src/variation-sweep.ts 64`；该脚本是保留的验证工具，不是一次性临时脚本。

## 验证及边界

23/23测试（原17项全部保留）：新增T0恒等、种子确定/多样/安全有界、T²均方扰动、快照重放与JSON校验、随机投掷跨render分组的完整物理及水滴一致、64种子真实结果多样。typecheck和production build通过；主JS约591kB，仍有500kB提示。

浏览器复用localhost:5173实际操作：
- T1新投seed=840866817：速度11.302439、仰角1.315073°、倾角5.096873°，7跳/8.1m/1.84s。
- 再投seed=3568270494：速度10.988934、仰角2.913744°、倾角6.111340°，6跳/9.0m/1.99s。
- 将滑块速度改15、温度改0，再重放第二次：完整JSON字符串不变，仍6跳/9.0m/1.99s。
- 恢复目标速度11，T0连续两投seed不同但sampled完全相同，均4跳/8.8m；这是实验回归，不是产品承诺。
- 恢复T1：seed=2558005234，实际速度11.125918、仰角2.912190°、倾角6.788201°，7跳/9.9m，页面目标/实际摘要正常。此样本不属于统计集合，也不用于替换集合边界。

这只验证当前工程模型中小初值变化带来的结果多样，不是实物噪声标定。临界姿态既有物理敏感性也有已知数值步长敏感性，原24组中5组跳数分歧尚在；本轮未对64组另做半步收敛，不能声称新增跳数全部对应现实可观察跳跃。未模拟真实风浪或温度对材料/水粘度的影响，未扩展场景、声音、商店，也未修改研究来源文档。
