## 看过之后的原始源码核对

本轮读取实际公开源和当前本地模块，不把旧审计当新体验证据。上游 URL 指向会变化的现行版本，本轮没有固定 commit。

### Evan 原始机制

- https://madebyevan.com/webgl-water/water.js
- https://madebyevan.com/webgl-water/renderer.js
- https://madebyevan.com/webgl-water/main.js （入口链接，本文数学核对来自前两个实际读取文件）
- 源码库：https://github.com/evanw/webgl-water

`water.js` 使用256²浮点双纹理，RGBA储存 `(h,v,nx,nz)`；邻域平均 `a=(hL+hR+hU+hD)/4`，每步 `v←0.995·(v+2(a-h))`，`h←h+v`，交换纹理；法线由高度差叉积算出。点击注入有限半径余弦平滑核，不是每帧重新画圆。拖球把旧位置近似排水量加回、减去新位置排水量：这是高度场体积代理，不是三维流体。

`renderer.js` 对简化池/球场景作反射与Snell折射射线求交，Fresnel混合。焦散把平水面与扰动后折射投影分别算为 oldPos/newPos，用 `length(dFdx(oldPos))*length(dFdy(oldPos)) / (length(dFdx(newPos))*length(dFdy(newPos))) * .2` 近似面积压缩聚光，再叠加遮挡。不要把这个受限场景的解析光路误称通用光线追踪渲染器。

### Three.js 鸭子机制（只有源码证据）

- https://threejs.org/examples/webgpu_compute_water.html
- https://github.com/mrdoob/three.js/blob/dev/examples/webgpu_compute_water.html

当前页为128²、6×6世界单位，计算 storage buffer A/B ping-pong，另存上一时间层；`hNext = viscosity·((hN+hS+hE+hW)/2-hPrev)+mouseSource`，默认viscosity=.96。鼠标有限余弦核乘移动速度，网格顶点真实位移，邻域高度差同时用于法线。speed默认5，通过渲染帧计数达到 `7-speed` 才推进，并非带真实秒单位的流体黏度参数。鸭子采样局部高度/坡度更新姿态/运动；这仍不是液片、飞滴或拓扑破碎求解。

### 当前 rendering 实现，不能沿用旧版错误描述

- `heightfield.ts` 已有真实h/v、512×256 CPU网格、16×8m域、120Hz固定步、c=.85m/s、拉普拉斯传播与吸收边带；不是“还没有高度场”。dx≈3.13cm，8cm石头长轴仅约2.6格，.045m最小接触半径约1.44格。**参考网格总数少并不意味着我们接触分辨率更好**，必须对照世界尺寸。
- `effects.ts` 在 `field.advance(time)` 后注入速度源；`heightfield.disturb()` 改v而非h，所以下一个120Hz水步才出现几何高度，最多约8.33ms相位等待；正常速度不应夸大为肉眼必然明显，但0.05×时可对应最多约167ms墙钟等待。片出生还有 `count>1`，即冲量达到.012后才有水舌；低冲量早触只见更弱波/滴，是否明显需逐帧验证。
- `water.ts` 已有真实场景平面反射、512²颜色/深度透射、F0=.0204和吸收；不是只反射天空渐变。但折射是有限屏幕UV偏移，非Evan解析射线；法线梯度统一乘2.6，深度差近似光程，无焦散。几何高度与夸大的光学斜率可能不一致。
- `effects.ts` 已经一次接触一条水舌、沿path出生节点演化，并有seed颗粒；不是仍然每批重复多张扇片。`sheets.ts` 的破洞噪声却固定在统一UV正弦频率，无每片seed uniform，近似宽度/横截面公式也共用；因此剩下的“相似”重点在轮廓/断边模式，而非旧版重复发片问题。

## 这轮最多四个可落实优先项

| 优先项 | 实施方向（本轮仅建议） | 验收与风险 |
|---|---|---|
| 1. 接触早期延迟与空间分辨率 | 首先保留事件时刻并检查水步内注入顺序/相位；以局部接触patch或局部细化解析小湿区，不先全域加密。明确早触凹陷/隆起到可见高度的时刻；分离水舌阈值与基础接触反馈。 | 同seed首触0–50ms、正常/0.05×对照，记录事件→h/法线首响应，不让基础响应等到水舌阈值。不能预先喷溅、不能提高冲量改跳数；细化须复核CFL和CPU成本。 |
| 2. 波形与传播层次 | 保留已有有状态求解；根据真实湿区、轨迹、法线、冲量增量形成前缘隆起/尾部凹陷和不同尺度的有限波包，先做单源与双源相交对照，再调核宽、阻尼、波速。 | 看见“源处形成—向外离开—相交—衰减”，不贴白环；不同接触不都出同宽同圆的波。现c常数模型不含真实毛细/重力色散，不宣称单纯调参数即可解决全部尺度。 |
| 3. 材质清晰度与光学一致性 | 用临时诊断参照物/底部刻度检查真实h、法线、反射/透射的对应，先评估2.6梯度放大与512²捕获模糊，再按近景需求分配分辨率/透射权重；保持湖水吸收，不复制蓝瓷砖泳池。 | 同机位同曝光，水下物仍可辨但有连续畸变，反射不糊成纯色；浅/掠射视角合理。焦散是有条件的下一层，不是第一步加满亮纹，也不是深湖必需效果。 |
| 4. 喷溅重复形态与分层温度 | 以真实contact path/湿区/冲量方向决定主水舌，把有seed的局部扰动分配给横向宽度、薄边缺口、边滴尺度；改变局部相位与相关长度而非每片只换整体朝向。 | 固定seed可重放，改变视觉seed只改细节、不改石头轨迹/跳数；低能量不凭空长大幕。同一接触仍连续，不能换掉当前一接触一片架构重新叠扇。高度场参考不提供体积破碎答案。 |

## 分层“温度”随机性合同

“温度”指可控的扰动幅度，不是模拟热力学。主物理和视觉细节必须分层，不能随机生成目标跳数。

1. **真实接触层：不加随机代替因果。** 接触时刻/位置、当前湿区、石面法线、速度、净冲量方向/增量、离水时刻、弹道落点决定主波能量、主水舌方向/包络、基础出滴时机。初次接触前不凭空起水花；既有物理投掷温度只在创建投掷时采样快照，不在渲染每帧重抽。
2. **事件/形态层：低温、有界、有seed。** `hash(throwSeed,contactId,channel)` 冻结每次接触的形态参数；主轴扰动建议先限±3°、宽度/局部核尺度±5–10%，且只作用视觉剩余自由度，不改变真实接触中心和累计能量预算。数值是待实图标定的起始上限，不是实测最优值。不同通道隔离，增加一颗滴不应改整片随机序列。
3. **局部边缘层：可略高温，但空间/时间相关。** 在归一化路径弧长、片UV、出生节点时间上采样平滑seed场，固定相关长度；边厚/缺口、边滴大小和小角度偏离可在约±10–20%内，低能量再收紧。破洞随拉伸/年龄连续增长；滴的状态出生后冻结，之后走同一弹道，落水源只触发一次。不能每帧白噪声制造闪烁、跳边、随机亮斑。
4. **光学微扰层：极低温。** 微法线幅度远小于接触坡度，只调高频细节，不用随机闪光替代传播/焦散。共享稳定seed坐标系，暂停/重放保持图案，不靠时间随机数刷新表面。

建议先用T=0验证主因果，再同一物理快照比较视觉T=低/中；若提高T改变跳数或主波到达时间，就越界。当前 `randomAt()` 和冻结粒子已提供确定性基础，不需另造全局随机系统；主要缺口在每片材质/断边缺少独立且连续的局部场。
