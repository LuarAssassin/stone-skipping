# 石子种类、Blender 建模规范与「拣石收集」系统设计

> 目标：让玩家在暮色湖畔体验「低头挑一块顺手的好石头 → 端详薄厚姿态 → 甩出破纪录」的真实乐趣。岸边石头天然**参差不齐**（有厚重砸水的烂石头，也有可遇不可求的极品薄圆盘），每一块石头的尺寸、厚度、质量、密度与阻力都**直接接入底层 4000 Hz 物理引擎、GPU 水场排水与音频合成**，绝不做假数值。

---

## 一、底层物理联动机制（为什么个头大真的水花大、声音大？）

当前原型中，石子的半轴与质量在 `src/simulation/physics.ts` 与 `src/app/session.ts` 中写死为单一基准（`80×60×9 mm`、`59.94 g`）。
升级为 `StoneSpec`（石子物理规格对象）后，一套参数将自动贯穿物理、水体、飞溅与声音四个系统：

| 石子物理参数 | 底层联动系统 | 玩家直观感受到的差异 |
| :--- | :--- | :--- |
| **半轴尺寸 `a, b, h` (m)** | `physics.ts` 椭圆湿面积 & 转动惯量；`session.ts` GPU 排水椭圆 `Footprint` | 盘面越大越容易被水面托起；越厚（`h` 大）入水排开水坑越深、阻力急增、极易一头栽进水里 |
| **质量 `mass` (kg) & 密度 `rho`** | 动量 `m·v`、重力、水下浮力 `1000·g·(mass/rho)` | 轻石子起跳门槛低但掉速快飞不远；重石子需要更大臂力，一旦起跳惯性惊人、水波波幅大 |
| **表面水阻系数 `dragScale`** | 擦水切向阻力 & 自旋阻尼 | 光滑磨圆的河石掠水顺滑保速；粗糙多孔石子擦水减速快、尾迹白沫（`SurfaceChurn`）更明显 |
| **形状规整度 / 重心偏移 `wobble`** | 接触压力偏心力矩微扰 | 歪瓜裂枣的碎石每次触水容易歪头失稳或莫名偏航；轴对称圆盘陀螺稳如钟表 |
| **体积 & 冲量 → 视觉与声音** | `spray.ts` 接触做功预算、`water-grid.ts` 反冲量、`audio/engine.ts` | **大/重石子砸水**：排开更大水坑、喷起更高水幕与更多水滴，音频基频更低沉、拍水与沉水“咕咚”更厚重；**小薄石子**：水花轻细、声音清脆灵动 |

## 三、Blender 建模与导出统一技术规范

为确保新模型放进 `public/assets/stones/` 后能与现有 4000 Hz 物理椭圆和落日 PBR 光照无缝严丝合缝，请在 Blender 中遵守以下 6 条硬规范：

1. **真实米制尺寸（1 Blender Unit = 1 Meter）**
   - 场景单位设为 `Metric`，`Unit Scale = 1.0`。
   - 严格按上表毫米尺寸建模（例如 `84 × 64 × 5.2 mm` 即 `X = 0.084 m, Z = 0.064 m, Y = 0.0052 m`），**导出前必须执行 `Ctrl + A` → Apply All Transforms（Scale 必须为 `1, 1, 1`）**。
2. **坐标轴与质心约定（严格对应 `physics.ts` 与 glTF 右手系）**
   - 原点 `(0, 0, 0)` 位于石子的**几何质心（Origin to Center of Mass / Volume）**。
   - 导出 glTF（Y-Up）后：
     - **`+X` 轴**：石子最长轴（默认沿前进投掷方向）；
     - **`+Y` 轴**：石子最扁平的盘面法向（朝天）；
     - **`+Z` 轴**：石子次长轴（宽度方向）。
   - *在 Blender（Z-Up）里建模时*：长轴沿 `X`，宽轴沿 `Y`，最薄的厚度沿 `Z`；导出 glTF 2.0 勾选默认 `+Y Up` 即可自动正确映射！
3. **面数与拓扑预算**
   - 单块石子控制在 **`400 ~ 1,200` 三角面**（光滑细分 + 法线贴图表现细节，不要直接导出几万面的高模雕刻网格）。
   - 必须为闭合流形网格（Manifold），平滑着色（Shade Smooth）避免出现硬折痕。
4. **PBR 材质规范（适配落日电影光影）**
   - 使用标准 `Principled BSDF`：
     - `Base Color`：偏自然低饱和（sRGB 亮度不要过亮，落在 `0.15–0.48` 区间，落日强光下才显质感）。
     - `Roughness`：干石表面 `0.58–0.85`（光滑河石 `0.45–0.60`，粗糙碎石 `0.80–0.92`；游戏引擎会在石子首次触水后动态降低粗糙度模拟湿润反光）。
     - `Normal Map`：推荐 `512×512` 或 `1024×1024`（细微岩层、砂砾与水磨凹痕），在低角度夕阳下质感会极其惊艳。
     - `Metallic`：保持 `0.0`（或云母/矿物微闪 `<= 0.08`）。
5. **导出格式与体积**
   - 格式：`glTF Binary (.glb)`，开启 `Draco` 压缩（或常规导出）+ 内嵌 `WebP/JPEG` 贴图，单文件体积控制在 **`80 KB ~ 350 KB`**。
6. **资产目录与清单**
   - 存放路径：`public/assets/stones/<id>.glb`，在 `src/simulation/stones.ts` 注册其真实尺寸、质量、阻力与品相描述即可热插拔接入游戏（建模完成前，引擎可先用程序化变形网格占位验证所有物理手感）。

## 四、「岸边拣石头 & 石匣收藏」核心玩法循环

不搞数值商店、不卖数值加成，而是还原真实河边打水漂最让人上瘾的仪式感——**「寻石 → 端详 → 收藏 / 试投」**：

1. **岸边寻石（Shore Foraging）**
   - 点击左下角 **「拣石头」**（或每次打完一轮），镜头轻俯到暮色浅滩碎石带（或弹出优雅的岸边石盘浮层），地面自然散落 **5 块新刷出的天然石头**（品质参差不齐：通常 2 块钝/碎石 + 2 块寻常扁石 + 1 块高概率精良/极低概率稀有石）。
   - 玩家点击任意一块可以**拿在手里 3D 旋转端详**——直接通过肉眼看它的薄厚、圆润度，并配有一句克制的自然手感直觉描述（如 *「薄而修长，压手适中」*、*「太厚了，怕是只能砸个响」*），不直接剧透“能跳 X 下”。
2. **「即扔」与「收入石匣」双选择**
   - **顺手一试**：直接拿去投出（消耗掉这块岸边临时石，砸水听个响也很快乐）。
   - **收入石匣（最多收藏 8 块心头好）**：遇到品相绝佳的薄页岩或极品黑曜圆盘，可以点「收藏」放进随身石匣。石匣里的石头**永久保留、可随时反复练习与刷纪录**（类似高尔夫球包），并记录每块藏石创下的最高跳数与最远距离。
3. **无压力探索感**
   - 岸边随时可以点击「沿岸再找找（换一批岸边石）」，累计弹跳次数达到里程碑（如累计 20 跳、100 跳、单投 15 跳）后，沿岸会解锁更上游的「页岩滩」「玄武湾」，提升刷出稀有好石头的概率。
