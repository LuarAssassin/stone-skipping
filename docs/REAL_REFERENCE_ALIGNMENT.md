# 真实案例对齐 · 2026-11-17

## 用户目标与证据边界

用户提供五张真实视频截图，要求按理想无扰动约90次弹跳设立目标，并先确定合理尺度，再改善水体。90是最佳工况的研发目标，不是所有T0出手的保证，也不作为计数上限或预设分数。

本轮暂定总距离50m、校准区间40–60m。这是设计目标，不是88跳纪录的实测距离。以90次触水估计，均匀间距约0.56m只是总量直觉；具体间距必须由模拟产生。前段可以几米，后段可能只有十几厘米，也可能有连续擦水；持续接触不能冒充多次跳跃。透视还会压缩远处的视觉间距。

## 五张图的视觉理解

1. 水线近景：石头旁有连续薄水幕，边缘破碎成离散细滴；水下存在凹陷/空腔轮廓，不能用一个平面圆圈代表。单帧不用于推断确切速度或喷射方向。
2. 岸后远景：一串宽而扁的触水区域，新水花小且锐利，旧扰动更宽、更平。远处密集感包含透视因素。
3. 近岸首触：暗色凹陷中心、亮水缘和少量向外飞滴同时出现；岸景反射被局部扰乱，而周围水面仍平静。
4. 叠加水迹：宽亮弧/波面互相覆盖，沿前进方向逐渐缩小，不能把整片白色直接认定为泡沫。
5. 末段：近水线、低矮且短的扰动串，与细长暗亮尾迹接近连成线；远处不能逐圈辨认90个圆环。仅凭这张图不能验证字幕声称的次数。

参考验收应覆盖：正常1×的完整一投、首触近景、末段密集小跳、沉水后余波；相同快照/机位的飞溅开关对照。前段水幕、尾段低扰动的差异比统一放大水花更重要。

## 本轮水体改动

新增 `simulation/spray.ts` 与 `rendering/spray.ts`，在固定物理步采样当前接触的冲量增量与速度，以负功的2.5%作为视觉发射能量预算。从湿区形心附近连续发射，水平速度低于石头、沿入射方向散开，细滴由重力决定高度及落水时刻；出生数据不被后来接触回写。粒径0.25–1.5mm，最多4096颗，真实尺寸，不放大石头或法线。材料使用IOR1.333的透射水滴。

这是单向、经验的接触驱动飞溅层，不是完整流体：2.5%分配和喷速/方向为工程闭合；未从高度场扣除水量/能量，因此不能声称联合守恒；回落暂未向水场注入次级波。当前只补离散细滴，还未补参考图1的连续薄水幕、空腔与真实破裂。旧liquid/sheets渲染路径保持退役。

DEV可复验：`/?reference=0.30` 使用T0、seed271、固定首触侧机位，`&spray=off`关闭新细滴供对照。此入口不会出现在生产构建的正常操作中。

首次截图发现漫反射水滴像不透明颗粒，已改透射材质、缩小半径并扩大取景。最终0.30s同机位可见石头离水后细滴留在后方，原波纹保留；这仍未达到参考图连续水幕的质量。截图见 `deliverables/reference-alignment/{before,after}-030.jpg`。
