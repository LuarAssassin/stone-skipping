# 掠水 · Stone Skipping

> 固定全域细网格候选版：石头的波纹/离水尾迹已有改善，强烈压水、水脊和腾空水花仍未达标。

TypeScript / Three.js / Vite网页打水漂。80×60×9mm真实米制石头；固定步姿态、自旋与续跳模拟，不预设成绩。物理与有种子出手采样保持不变。

## 本版水面

- 连续16×8m、2048×1024 RGBA32F水场，格距7.8125mm；固定全域保留旧尾迹，不是移动补丁。
- 120Hz命令、每命令5子步，CFL=.8；保持米制传播速度和每秒阻尼，顶点/坡度/状态共享栅格中心坐标。
- 定向排水代理沿子步运动，四点Gauss采样和域内解析体积归一。真实竖直反冲量按实际湿面积确定米制核，并离散归一进入水面速度；不以改格距或放大石头增加冲量。
- 鼠标和石头共用同一水场。默认无旧膜、管、杆球饰件；计分结束后波面继续演化。
- 改编Evan Wallace的波面更新、法线与聚光方法，结合Three反射和近似屏幕空间透射。**部分光学适配，不是完整上游解析泳池渲染器；没有翻卷、液片撕裂或腾空水花。**

来源与完整MIT见[第三方说明](THIRD_PARTY_NOTICES.md)及`public/third-party/evanw-water/`。校准床/天空程序自绘，不使用上游照片。项目整体当前未另授予开源许可证。

## 运行与操作

Node.js20.19+或22.12+。

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build
```

湖面按住约0.7秒拖动并松手投石；横拖方向、上下拖仰角。勾选「鼠标拨水验证」可直接拨水，点击「投出石子」退出。暂停、单步、相机、0.25x/0.05x回放与旧v1快照保持。旧视觉字段保留但暂停使用的空中水花温度控件明确禁用，物理出手温度仍有效。

`predev/prebuild`从`public/assets/stone.glb.base64`恢复原始模型；部署使用构建后的`dist/`。

## 验证和局限

85项：**75通过、0失败、10项旧渲染器用例明确停用**，物理/出手/快照合同保持。新增米制核/排水体积、CFL/阻尼、出生时序、栅格上传中心和细化性质检查。实际GPU另验证源预算、传播收敛、清场与完整投掷后正常/慢放/子弹的状态一致；不把这些数值作为视觉通过。

质量代价明显：桌面3秒短测约33FPS平均、RAF p95 63ms，有长尾；不保证稳定60FPS或移动端性能。只有竖直反冲、经验参与深度和线性波面，存在平均水量误差；强烈石水冲击仍不足。太阳亮带不是水波，鼠标大扰动也不能替小石头通过验收。研究、对照截图和日志保留在本地，不随公开源码上传。
