# 掠水 · Stone Skipping

> 连续水面基线候选版。鼠标交互的整片波面已可运行；真实小石头的接触与沉水反馈仍偏弱，未宣称达到参考演示画质。

TypeScript / Three.js / Vite 网页打水漂实验。石头轨迹、姿态、自旋与续跳由固定步模拟产生，不预设成绩。

## 本版水面

- 改编 Evan Wallace WebGL Water 的浮点纹理双缓冲高度/速度更新、坡度法线、旧排水归还/新排水移除，以及投影面积比聚光。
- 鼠标和真实米制石头走同一120Hz命令与同一演化水面；默认不渲染旧薄片、厚缘管、液丝和球滴饰件。
- 石头的竖直接触反冲量按离散归一核进入水面速度状态；密度1000kg/m³、参与深度4cm属于当前简化模型。只耦合竖直反冲，不是完整流固耦合；存在有限平均水量误差。
- 实际场景反射、屏幕空间透射、吸收与近似焦散；不是上游完整解析池光线求交渲染器。没有腾空水体、翻卷波浪或破碎液片能力。
- 实际计分/物理结束后，已有水面继续演化。旧视觉元数据保持兼容，但暂停使用的空中水花温度控件明确禁用，不伪造效果。

来源、精确上游修订与完整MIT文本见 [第三方说明](THIRD_PARTY_NOTICES.md) 和 `public/third-party/evanw-water/`。校准床和天空为程序自绘，不使用上游照片贴图。项目整体当前未另授予开源许可证。

## 运行与操作

Node.js 20.19+ 或22.12+。

```sh
npm ci
npm run dev
```

- 默认在湖面按住约0.7秒，横拖调方向、上下拖调仰角，松手投石。
- 勾选「鼠标拨水验证」可直接拖水，观察同一波面传播与交汇；点击「投出石子」退出验证模式。
- 保留暂停、单步、跟随/岸后视角、0.25x慢放和0.05x环绕回放。
- 出手温度默认1；完整JSON快照保留实际出手，重放不重新抽样。

`predev`和`prebuild`会从`public/assets/stone.glb.base64`恢复原始Blender模型；部署使用构建后的`dist/`。

