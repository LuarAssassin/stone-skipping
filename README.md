# 掠水 · Stone Skipping

TypeScript / Three.js / Vite网页打水漂实验。石子姿态、自旋、有限水面接触与自然续跳由模拟计算，不预设成绩。

- 有种子的出手扰动、完整JSON快照与确定性重放；独立视觉seed与可折叠“水体细节扰动”三温度0..2（默认.35/.8/1.1），只影响下一次新投掷。v1旧JSON仍可载入，可选visual字段经验证保存；改视觉不改轨迹。
- 固定120Hz场用源时刻一阶矩校正步内早触，展示几何/法线共用高度；连续相关水舌轮廓、每片独立破洞与有界滴群，不每帧抽随机数。
- 局部16×8 m有状态高度/速度网格真实位移水面；沿接触轨迹、离水与落滴事件驱动，真实米制石子。
- 真实场景反射、颜色/深度透射与吸收；连续出生节点水舌替代重复扇片，仍为单向、非体积流体近似。
- 鼠标/触屏按住蓄力、拖动瞄准、松手投掷；Esc取消。
- 默认近岸后固定机位（高2.1 m、后退2.4 m），可调高度、距离、方位、注视点与FOV，保留远景范围、重置及跟随。
- 正常1x、慢放0.25x、贴水环绕子弹时间0.05x；暂停冻结轨道，退出恢复所选视角。新投恢复1x，重放不重新抽seed。

## 运行

需要Node.js 20.19+或22.12+。

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build
```

在湖面按住约0.7秒，横拖调整方向、上下拖调整仰角，松手投掷；快捷滑块调整石面倾角。视角与速度菜单常驻；开发详情保留全部出手参数、温度（默认T1）、辅助轨迹、单步、诊断和JSON重放。空格暂停，R新投。

predev/prebuild通过tools/prepare-assets.mjs从public/assets/stone.glb.base64恢复Blender原创GLB。构建后的dist/可独立静态部署，不需要外部工作区资产。

## 结构与验证

src/main.ts只负责启动；simulation、rendering、camera、input、ui与app/session分工。测试位于tests/，必要基线位于tests/fixtures/；tools/包含资产准备、参数扫描与显式校准工具。

```sh
npm run sweep
npm run sweep:variation -- 64
npm run calibrate -- /tmp/contact-report.json 64
```

58项测试（原52保留）覆盖物理/24组难例与64种子校准/手势/效果/镜头/三倍率重放，以及高度场传播/衰减/边界、不可变轨迹源、落滴一次与有界池；原43项保留，测试不覆写基准。新增16视觉seed实际轮廓/破洞/滴群独特性、全T0一致、早触相位、视觉metadata兼容与边界、逐tick轨迹不变回归。去掉光学坡度×2.6，反射/透射1024²，但细波仍弱、无焦散，不能宣称参考画质达标。类型检查与生产构建通过，Three.js主包仍有超过500kB的体积提示。

这是持续开发的工程近似，尚有极端末段接触收敛问题；水体为单向视觉反馈，不是完整流体求解。没有实体手机性能或实物标定结论。本轮不含准备阶段放大、顺逆自旋或游标力度；已接上弱落滴次级波源。近景仍有薄膜近似，常规机位波纹对比与正常桌面帧尾延迟仍需改善。第三方来源与完整依赖许可见THIRD_PARTY_NOTICES.md，它不为整个项目赋予许可证。研究笔记、完整实验日志、node_modules及dist不包含在公开源码中。
